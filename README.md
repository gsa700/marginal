# Marginal

*Notes in the margins of your music library.*

A small desktop editor for the tags, cover art and lyrics of a music library
you own: FLAC, MP3 and M4A. Open an album, see exactly what every file holds,
fix it by hand or from MusicBrainz, the Cover Art Archive and LRCLIB, see
every change before it is made, and write it safely. The audio is never
touched.

A companion to [AlbumWall](https://github.com/gsa700/albumwall) and
[Deadwax](https://github.com/gsa700/deadwax), and useful without them.

**Status:** being designed. Nothing to install yet. See
[docs/spec.md](docs/spec.md) and [docs/roadmap.md](docs/roadmap.md).

macOS, Linux and Windows. Free software, GPLv3.
